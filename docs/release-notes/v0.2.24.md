# Oyenza Master 0.2.24

Brent, palladium and copper now use live market quotes when the central market
hub returns an outdated response. Crude palm oil now uses the Malaysian Palm
Oil Board's daily local-delivered price in MYR per tonne; it is shown as a
daily physical price, not as an FCPO futures quote. These fallback requests run
only while the Forex & Commodities page is open.

The market hub keeps the public address `api.dollarkilat.xyz`, caches provider
quotes, and backs off after rate-limit responses. This installer build does not
create a release tag or publish a GitHub release.
