# Oyenza Master 0.2.23

## Forex and commodities

- Fix market quotes and historical charts that failed to load because the hub
  response did not match the desktop's data format.
- Replace fixed commodity prices with provider data. Share cached provider
  responses and honor rate-limit retry delays on api.dollarkilat.xyz.
- Keep the last available data during an outage instead of replacing it with
  sample prices or invented chart movement.
- Correct VND quote units, agricultural futures prices quoted in US cents,
  dollar formatting, and IDR conversions for precious-metal charts.
- Avoid retaining Windows HTTP-cache snapshots between market refreshes.

The Windows installer upgrades the existing Poni installation in place. No new
runtime dependencies, idle timers, or background polling were added. The server
source must also be deployed to api.dollarkilat.xyz for the hub changes to go live.

This version is prepared for an installer build. No release tag or public GitHub
release is created by the source push; website release publication remains a
separate release step.
